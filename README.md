# Personal Portfolio Website

## 📌 Project Overview

This project is a personal portfolio website developed as part of the **WeIntern Week 1 Web Development Internship**.
It showcases my profile, skills, projects, and contact information through a clean, professional, and responsive website.

## 🎯 Objectives

- Create a professional personal portfolio.
- Practice HTML5, CSS3, and JavaScript.
- Build a responsive website for desktop, tablet, and mobile devices.
- Showcase personal information, technical skills, and projects.
- Implement interactive navigation and a contact form.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, responsive layouts, animations, and transitions
- **JavaScript** — Interactive navigation and website functionality

## ✨ Features

- **Home Page:** Introduction and welcome section.
- **About Page:** Personal introduction, education, and skills.
- **Projects Page:** Displays projects using styled project cards.
- **Contact Page:** Contact form for visitors to send messages.
- **Responsive Navigation:** Hamburger menu for smaller screens.
- **Responsive Design:** Adapts to different screen sizes.
- **Smooth Scrolling:** Provides smoother navigation between sections where applicable.
- **Hover Effects:** Enhances the user experience.
- **Contact Form:** Configured for submission through FormSubmit, if email integration has been set up.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the `task-1-portfolio` folder.
3. Open `index.html` in your web browser.
4. Navigate through the Home, About, Projects, and Contact pages.

You can also open the project folder in Visual Studio Code and use the Live Server extension for local development.
